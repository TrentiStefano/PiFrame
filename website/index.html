ANSWERS

Frequently Asked Questions

Does PiFrame collect telemetry or track my code? +

Strictly zero. In accordance with architectural Decision D16, PiFrame and pi-agentd contain zero tracking pixels, analytics SDKs, or cloud telemetry. The local daemon is bound strictly to loopback (127.0.0.1) and communicates only with your configured AI model provider via standard authenticated API requests.

How does disconnect-safety work when I close the app? +

PiFrame uses a decoupled three-tier architecture. When you start an agent action, the local daemon pi-agentd manages the session and appends every token, tool call, and terminal output to a local monotonic journal. If you quit the GUI window, restart your desktop shell, or lose connection, pi-agentd continues running. When you reopen PiFrame, it reads the journal sequence and synchronizes state seamlessly without duplicates or lost progress.

Can I switch between the terminal Pi CLI and the PiFrame GUI? +

Yes, completely seamlessly. PiFrame does not maintain a private proprietary database. All session history is stored directly in the official Pi session folder (~/.pi/agent/sessions/). You can launch a task in the terminal with pi, open PiFrame to inspect diffs visually, and return to the terminal at any time.

Which operating systems are supported? +

PiFrame provides native installers for Windows 10/11 (x64), macOS Apple Silicon (M1/M2/M3/M4), macOS Intel (x64), and Linux (Debian/Ubuntu x64). It also supports Windows Subsystem for Linux (WSL) repositories directly.

Can I use custom themes? +

Yes! PiFrame comes out-of-the-box with official PiFrame Dark (#161c27) and PiFrame Light (#f1f3f7) default palettes, crafted specifically for ergonomic developer focus. You can also import standard VSCode JSON theme files or place custom hot-reloadable JSON theme files into ~/.piframe/themes/.
