# Brag Plan: PiFrame Desktop

## What is this app?
PiFrame is a blazing-fast, 120fps native Flutter desktop GUI for pi-coding-agent featuring a decoupled disconnect-safe daemon, Bento ergonomics, split-diff reviews, and zero telemetry.

## The angle
Most AI coding agent GUIs are sluggish, 30fps webviews that freeze on large token streams and kill your work if you close the window. PiFrame proves that desktop AI developer tools should be native, instant, and disconnect-safe.

## Hook (first 2 seconds)
A high-velocity zoom into the sleek PiFrame Dark Bento workspace (#161c27) as high-framerate tokens and thinking blocks explode into the transcript at 120fps with zero latency.
Text: **"Stop coding with sluggish web wrappers."**

## Key moments (the middle)
- **120 FPS Fluidity & In-Flight Steering**: Live steer queue modifications and task completions streaming uninterrupted.
- **50/50 Review Diff & Instant Staging**: Side-by-side synchronized split diff with one-click atomic staging.
- **Universal Bento Control**: Integrated terminal, live web browser, and instant light/dark palette shift.

## Outro / punchline
A crisp slam to the glowing PiFrame dark logo with the core truth:
**"Zero Telemetry. Disconnect-Safe. Native Flutter."**

## User flow worth showing
1. **Prompt & Token Stream**: User submits an ambitious refactor; reasoning tokens flow smoothly.
2. **Review & Steer**: User reviews the 50/50 split diff, stages files, and injects mid-run directions into the steer queue.
3. **Execution & Continuity**: Window minimizes and restores instantly while daemon preserves 100% of the progress.
